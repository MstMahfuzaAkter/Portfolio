📋 About the Portfolio

This is a responsive single-page portfolio website built with modern web technologies. It presents:

👩‍💻 Projects – Frontend and full-stack applications

🛠️ Skills – React, Node.js, MongoDB, Firebase, and more

📄 Resume – One-click downloadable resume

📬 Contact Form – Integrated with EmailJS

🌐 Social Links – GitHub, LinkedIn, Instagram

The portfolio is designed to be clean, professional, and recruiter-friendly.

🛠️ Tech Stack

Vite – Fast and modern build tool

React.js – Component-based UI library

Tailwind CSS – Utility-first CSS framework

EmailJS – Backend-free email service

React Scroll – Smooth section navigation

Firebase Hosting – Deployment & hosting

🌟 Key Features

⚡ Blazing Fast Performance using Vite

📱 Fully Responsive Design (mobile, tablet, desktop)

🔍 SEO Optimized with meta tags & alt attributes

🧭 Smooth Navigation with React Scroll

🧩 Dynamic Sections:

Projects with live & GitHub links

Resume download button

Contact form with EmailJS

🚀 How to Run Locally

1️⃣ Clone the repository:

git clone https://github.com/MstMahfuzaAkter/Portfolio


2️⃣ Navigate to the project folder:

cd portfolio


3️⃣ Install dependencies:

npm install


4️⃣ Run the development server:

npm run dev


5️⃣ Open in browser:

http://localhost:5173
